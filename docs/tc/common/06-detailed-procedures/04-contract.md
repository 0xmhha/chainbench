## CT-CONTRACT-001 · 컨트랙트 배포

- **목적**: 컨트랙트를 배포하면 주소가 생기고 코드가 조회되는지 확인한다.
- **의존 요소**: 테스트 계정, 컨트랙트
- **분리 방식**: 설정으로 분리, 기대값은 체인별 계산
- **절차**:
    1. 정해진 값을 돌려주는 작은 컨트랙트를 배포한다.
    2. 영수증의 컨트랙트 주소로 코드를 조회한다.
    3. 호출해 반환값을 확인한다.
- **기대 결과**: 코드가 비어 있지 않다. 반환값이 42다.
- **체인별 차이**: 배포할 코드가 세 체인의 EVM에서 모두 실행돼야 한다. WEMIX3.0은 최신 명령어(PUSH0)를 지원하지 않는다.
- **비고**: 기존 명세: RT-A-3-01, TX-005 / 자동 테스트: contract-roundtrip, wemix-tx-and-contract (PR196-TC-004), wbft-tx-and-contract (PR196-TC-027) / PR196 우선순위: P1/P2 / PR196에서는 네 가지 형식으로 각각 배포한다.

## CT-CONTRACT-002 · 상태 변경 함수 호출

- **목적**: 저장값을 바꾸는 함수를 호출하면 바뀐 값이 조회되는지 확인한다.
- **의존 요소**: 테스트 계정, 컨트랙트
- **분리 방식**: 설정으로 분리, 기대값은 체인별 계산
- **절차**:
    1. 저장값 컨트랙트를 배포한다.
    2. 저장값을 바꾸는 트랜잭션을 보낸다.
    3. 조회 함수로 값을 읽는다.
- **기대 결과**: 상태가 성공이고 읽은 값이 바꾼 값이다.
- **체인별 차이**: CT-CONTRACT-001과 같다.
- **비고**: 기존 명세: RT-A-3-02, TX-005 / 자동 테스트: stablenet-register-contract (PR196-TC-036) / PR196 우선순위: P1/P3 / 등록된 컨트랙트 호출 자동 테스트와 절차가 겹친다.

## CT-CONTRACT-003 · 조회 함수 호출

- **목적**: 트랜잭션 없이 조회 호출로 값을 읽을 수 있는지 확인한다.
- **의존 요소**: 컨트랙트
- **분리 방식**: 설정으로 분리, 기대값은 체인별 계산
- **절차**:
    1. 배포된 컨트랙트의 조회 함수를 호출한다.
- **기대 결과**: 정확한 값이 돌아오고 상태는 바뀌지 않는다.
- **체인별 차이**: CT-CONTRACT-001과 같다.
- **비고**: 기존 명세: RT-A-3-03, TX-005 / PR196 우선순위: P1/P2

## CT-CONTRACT-005 · 조회 호출의 되돌림 오류

- **목적**: 되돌리는 함수를 조회 호출하면 오류와 사유가 돌아오는지 확인한다.
- **의존 요소**: 컨트랙트
- **분리 방식**: 설정으로 분리, 기대값은 체인별 계산
- **절차**:
    1. 되돌리는 함수가 있는 컨트랙트를 배포한다.
    2. 그 함수를 조회 호출한다.
- **기대 결과**: 실행 되돌림 오류가 돌아온다.
- **체인별 차이**: 기존 자동 테스트의 컨트랙트 코드가 PUSH0을 써서 WEMIX3.0에서는 배포가 실패한다. 세 체인에서 실행되는 코드로 바꾼다.
- **비고**: 기존 명세: RT-A-3-05 / 자동 테스트: eth-call-revert-returns-error / PR196 우선순위: P1/P2

## CT-CONTRACT-006 · 되돌림 트랜잭션의 실패 상태

- **목적**: 되돌리는 함수를 트랜잭션으로 실행하면 영수증 상태가 실패이고 상태 변경이 없는지 확인한다.
- **의존 요소**: 테스트 계정, 컨트랙트
- **분리 방식**: 설정으로 분리
- **절차**:
    1. 항상 되돌리는 컨트랙트를 배포한다.
    2. 호출 트랜잭션을 보낸다.
    3. 영수증 상태를 확인한다.
- **기대 결과**: 배포는 성공, 호출은 실패 상태다. 쓴 가스만 차감된다.
- **비고**: 기존 명세: RT-A-3-06, TX-017 / 자동 테스트: revert-tx-status-zero, wbft-revert-status-zero, wemix-revert-status-zero, stablenet-negative-tx-revert (PR196-TC-022) / PR196 우선순위: P1/P2 / 세 체인용 자동 테스트가 이미 있다.

## CT-CONTRACT-007 · 가스 소진 트랜잭션

- **목적**: 가스 한도를 부족하게 주면 실패하고 가스를 전부 쓰는지 확인한다.
- **의존 요소**: 테스트 계정, 컨트랙트
- **분리 방식**: 설정으로 분리
- **절차**:
    1. 무한 반복 컨트랙트를 배포한다.
    2. 가스 한도 50,000으로 호출한다.
    3. 영수증을 확인한다.
- **기대 결과**: 실패 상태이고 사용 가스가 50,000이다.
- **비고**: 기존 명세: RT-A-3-07, TX-018 / 자동 테스트: out-of-gas-consumes-all / PR196 우선순위: P1
