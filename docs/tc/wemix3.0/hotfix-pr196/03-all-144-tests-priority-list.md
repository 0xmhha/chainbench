## 목록 안내

기존 테스트 후보는 총 144개다. 우선순위별로 P0 4개, P1 89개, P2 44개, P3 7개이며, 문서 명세 47개 항목과 JSON으로 정의된 자동 테스트 97개로 구성한다. 같은 기능을 다루는 항목이 포함되어 있으므로 144개가 모두 서로 다른 테스트를 뜻하지는 않는다. 신규 테스트 N-001\~N-016은 이 목록에 포함하지 않는다.

기존 명세의 테스트 ID는 유지한다. 명세 ID가 확인되지 않은 37개 항목에는 PR196-TC-001\~PR196-TC-037을 부여하고 상세 정보에 “(테스트ID 미부여 케이스)”를 표시했다. 기존 테스트를 관리하기 위해 부여한 ID이며, 대응하는 원본 명세는 아직 확인하지 못했다.

상세 정보의 링크는 Chainbench 원본 명세로 연결된다. 링크가 있어도 자동 테스트가 명세의 모든 조건을 검증하는 것은 아니다. 이 문서는 기존 테스트의 참고 목록이다. 실제 수행 및 결과 집계 대상은 집중 테스트 28개(P0 3개, P1 20개, P2 4개, P3 1개)와 상세 절차의 필수 세부 조건이다. RT-A-1-07과 PR196-TC-001(wemix-chain-up)은 집중 수행 범위에서 제외했지만 기존 테스트 이력을 유지하기 위해 이 목록에는 남긴다. 신규 테스트의 혼합 노드 구성 항목은 집중 수행 범위에서 제외했으며, 원래 이 144개 목록에는 포함되지 않는다.

자동 테스트의 기대 결과는 기존 코드에 작성된 검증 조건을 요약했고, 문서 기반 항목은 원본 명세의 기대 결과를 정리했다. 다른 환경에서 가져온 테스트는 WEMIX3.0의 하드포크, 수수료, PoA 및 etcd 구성, 계정과 RPC 설정에 맞게 수정한 뒤 실행한다. 구체적인 오류 메시지와 동기화·수수료 정책은 테스트 대상 패치 버전을 기준으로 확인한다. 집중 테스트의 추가 확인 사항은 기존 자동 테스트가 이미 검증한다는 뜻이 아니다. 유형별 전송 항목은 최신 상세 절차처럼 각각 유지한다. RT-G-4-02의 상태 유지 방법과 N-008의 queued 교체 절차는 댓글 검토 사항으로 남아 있으며, 구체적인 실행 조건을 확정한 뒤 수행한다.

테스트 제목 아래에는 원본 실행 이름 또는 문서 항목을 찾기 위한 참조 번호(TC-xxx, DOC-C-xxx, DOC-D-xxx)를 표시한다. 이 참조 번호는 테스트 ID와 구분한다. 같은 명세 ID가 여러 행에 있으면 각 행의 검증 범위를 확인한 뒤 결과를 기록한다. 기대 결과의 RPC 필드명, 변수와 수치는 원본 검증 조건을 식별할 수 있도록 유지했다.
