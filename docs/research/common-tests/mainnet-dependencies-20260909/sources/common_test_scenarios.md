# WEMIX Common Test 시나리오 명세서 (WEMIX Common Test Suite)

본 문서는 Chainbench 및 테스트 수트 시나리오 중에서 WEMIX 체인 생태계(WEMIX3.0, WEMIX4.0, StableNet 등)에서 공통적으로 테스트 및 검증이 가능한 표준 테스트 시나리오만을 선별·분류하여 작성한 명세서입니다.

---

## 분류 및 검증 범위 (Scope & Classification)

### 포함 대상 (WEMIX Common Test)

- **표준 트랜잭션 규격 및 타입**: Legacy (Type 0x0), Dynamic Fee (EIP-1559 Type 0x2), Access List (EIP-2930 Type 0x1), Fee Delegation Dynamic Fee Tx (Type 0x16)
- **메모리풀(Mempool/TxPool) 및 트랜잭션 검증**: Nonce 순서 보장, 잔액 부족 거부, Gas Limit 초과 거부, TipCap 미달(Underpriced) 거부, Replacement Tx(동일 Nonce + 높은 가스비 교체), Effective GasPrice 계산 및 노드 간 일관성
- **EVM 스마트 컨트랙트 실행**: 컨트랙트 배포, 상태 변경 함수 호출, View/Pure 함수 조회(`eth_call`), 가스 추정(`eth_estimateGas`), Revert 실행(상태 롤백 & 가스 환불), Out-of-Gas(가스 Limit 전액 소모)
- **표준 JSON-RPC API**: `eth_*`, `net_*`, `txpool_*` 표준 쿼리 및 WebSocket 구독(`eth_subscribe`)
- **노드 동기화 & P2P 네트워크**: Genesis 초기화, Full Sync, Snap Sync, 노드 재기동, P2P Bootnodes 피어 연결, Block Fetcher/Downloader 경로

### 제외 대상 (제외 항목)

- **EIP-7702 (SetCode Tx / Type 0x4)**: 계정 코드 위임 관련 시나리오 제외
- **체인 전용 특수 거버넌스 컨트랙트**: 특정 체인 고유 시스템 컨트랙트 (`0x1000` NativeCoinAdapter, `0x1001` GovValidator, `0x1002` GovMasterMinter, `0x1003` GovMinter, `0x1004` GovCouncil, `GovConfig`, `GovStaking`, `GovNCP` 등)
- **특수 가스 정책 및 특수 합의 RPC**: Anzeon 특수 가스 변동률 정책 (MinBaseFee 20Gwei 제어, `GasFeeCap < baseFee + MinPriorityFee` 조건 강제 거부, 20% 가스 사용률 타겟 등), Istanbul/WBFT 전용 RPC (`istanbul_*`)
