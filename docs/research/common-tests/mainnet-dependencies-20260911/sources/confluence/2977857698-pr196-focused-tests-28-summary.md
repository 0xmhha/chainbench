## 목록 안내

집중 테스트는 총 28개다. 우선순위별로 P0 3개, P1 20개, P2 4개, P3 1개이며, 기존 테스트 20개와 신규 테스트 8개로 구성한다. 기존 명세 ID는 유지하고 신규 항목은 ‘신규 테스트’로 표시한다.

go-wemix가 지원하는 트랜잭션 유형 0x0, 0x1, 0x2, 0x16의 정상 처리를 확인한다. 컨트랙트 배포, 상태 변경 및 이벤트 테스트는 네 가지 유형으로 각각 실행하고 결과를 따로 기록한다. 각 행의 상세 절차에서 준비 사항과 판정 기준을 확인한다. 이 문서는 테스트 계획이며 실행 결과는 별도로 기록한다.
