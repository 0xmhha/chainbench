## 목적과 문서 구성

WEMIX3.0 체인 중단 취약점 수정이 기존 기능에 미치는 영향을 확인하고, 동기화·트랜잭션 처리·블록 생성 등 주요 기능의 회귀 테스트를 수행한다.

이 페이지는 수정 영향 범위와 테스트의 관계, 수행 범위 및 완료 판정 기준을 관리한다. 기존 테스트 목록과 상세 절차는 원본 문서로 유지하고, 범위 결정과 실행 결과는 별도 페이지에 기록한다.

| 문서 | 용도 |
| --- | --- |
| 집중 테스트 31개 요약 (2977857698) | 이번에 수행할 집중 테스트 31개와 상세 절차 링크 |
| 집중 테스트 31개 상세 실행 절차 (2979070094) | 준비 사항, 실행 방법, 기대 결과와 판정 시 유의 사항 |
| 기존 테스트 전체 144개 우선순위 목록 (2978054308) | 주요 기능 전반의 후보 목록과 원본 명세 |
| 회귀 테스트 수행 범위 및 결과 기록 (2977988792) | 집중 테스트 31개의 실행 기준, 결과 및 유형별 세부 결과 |
| 테스트 용어집 (2978185459) | 문서에서 사용하는 기술 용어 |

## 검토 기준과 현재 상태

영향 범위는 기존에 보존한 [PR196](https://github.com/wemixarchive/go-wemix/pull/196) 분석을 기준으로 정리했다. 비교 기준은 수정 전 c8321f, 수정 후 5a9355다. 아래 대응표는 이 기준의 검증 계획이며 실제 실행 결과가 아니다. 실행 대상 통합 버전은 아직 확정하지 않았다. 대상 버전이 달라지면 변경 내역과 제한값을 다시 확인하고 해당 실행 회차의 기준을 결과 페이지에 기록한다.

이번 수행 범위는 집중 테스트 31개와 상세 절차의 필수 세부 조건으로 확정했다. 전체 144개 목록은 참고 자료로 유지한다. 실제 테스트 실행 및 결과 정리는 완료되지 않았다. 코드 분석에서 확인한 경로 차이를 실제 장애나 취약점 재현 결과로 기록하지 않는다.

## 수행 범위 결정 원칙

이번 회귀 테스트의 수행 범위는 집중 테스트 31개와 상세 절차의 필수 세부 조건이다. P0 5개, P1 21개, P2 4개, P3 1개이며 기존 테스트 22개와 신규 테스트 9개로 구성한다. 컨트랙트 테스트의 유형별 실행 결과는 상위 항목에 연결하며 개별 테스트 수에 중복 합산하지 않는다.

전체 144개 목록은 회귀 테스트 후보와 원본 명세를 확인하는 참고 자료다. 이번 수행 결과의 집계 대상은 집중 테스트 31개이며, 144개 전체의 검토나 실행을 이번 완료 조건에 포함하지 않는다.

수행 범위를 확대할 때에는 추가할 테스트와 선정 사유를 별도로 합의한 뒤 실행 절차, 기대 결과 및 결과 기록 항목에 반영한다. 현재 결과 기록에는 집중 테스트 31개와 해당 항목의 필수 세부 조건만 포함한다.

## 집중 목록에서 제외된 검증 범위

아래 6개는 앞서 집중 테스트 요약과 상세 절차에서 제외한 범위로, 이번 집중 테스트 31개의 수행 대상에 포함하지 않는다. 관련 테스트를 통과하더라도 아래 범위까지 검증한 것으로 간주하지 않으며, 최종 결과의 검증 범위를 설명할 때 참고한다.

| 제외된 범위 | 현재 확인하지 못하는 내용 |
| --- | --- |
| 블록 RLP의 정확한 8 MiB 경계와 오류 우선순위 | 크기 초과 거부 테스트와 별개로 경계 직전·동일·직후 및 오류 순서는 미검증 |
| 두 블록 생성 처리 방식의 정확한 트랜잭션 추가 경계 | 종료 조건 테스트는 관련 동작을 다루지만 각 방식의 정확한 바이트 경계를 대체하지 않음 |
| 최종 블록 조립·서명 이후 크기와 수신 결과 일치 | 유형별 크기 비교만으로 실제 WEMIX 최종 생성 및 수신 경로 전체를 검증했다고 볼 수 없음 |
| 과거 크기 초과 블록 재처리와 동기화 방식별 정책 | 정상 체인의 Full/Snap Sync 성공만으로 과거 블록 재처리 정책을 확인할 수 없음 |
| ETH 메시지의 정확한 10 MiB 경계와 정상 대형 블록 전파 | 본문·receipt 응답 테스트만으로 전체 메시지 유형의 경계와 블록 전파를 확인할 수 없음 |
| 크기 제한 도달 후 etcd 블록 생성 권한 반환 | 일반 노드 기동·복구 테스트만으로 크기 제한 도달 시 권한 반환과 다음 블록 생성을 확인할 수 없음 |

수행 완료와 검증 통과는 구분한다. 테스트를 모두 실행했더라도 실패가 남아 있으면 패치 검증 통과로 표시하지 않는다. 현재 최종 검증 결론은 미정이다.

## 기존 문서 보존 원칙

기존 집중 테스트 요약·상세 절차와 전체 144개 목록의 본문, 테스트 ID, 기대 결과 및 원본 링크는 이번 업데이트에서 변경하지 않는다. 추가한 영향 대응표는 기존 분석과 테스트를 연결하는 자료이며, 기존 명세를 대체하지 않는다. 실행 결과와 범위 결정은 결과 기록 페이지에서 관리한다. 새로운 패치 버전으로 다시 실행할 때에는 이전 회차의 기준과 결과를 보존한다.
