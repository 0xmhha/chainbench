(보존 주의: 원문은 폐쇄망 15대 서버의 내부망 IP 목록과 sshpass 비밀번호 인자를 쓰는 원격 제어 스크립트 `node_ctrl.sh` 전문이다. 내부망 주소와 스크립트 본문은 보존본에서 생략하고 사용법 요약만 남긴다. 테스트 케이스 ID는 없다.)

**기본 형식**

```bash
./node_ctrl.sh <user> <password> <command> <all | 서버번호>
```

- 서버 번호는 IP 끝자리 기준 (1 ~ 15)
- `all` 지정 시 전체 서버(15대)에 순차 실행

**주요 커맨드**

| command | 동작 |
|---|---|
| `kill` | 노드 프로세스 종료 |
| `run` | 프라이빗 노드 기동 |
| `run_mainnet` | 메인넷 기동 |
| `run_testnet` | 테스트넷 기동 |
| `restart` | kill → 종료 확인 → run (자동 검증 포함) |
| `restart_mainnet` | kill → 종료 확인 → run_mainnet |
| `restart_testnet` | kill → 종료 확인 → run_testnet |
| `init` | 초기화 |
| `upload` | 로컬 파일 → 원격 서버 전송 |
| `download` | 원격 서버 파일 → 로컬 수신 |
| `del` | kill.sh 실행 → 종료 확인 → /data/stableNet/gstable 폴더 삭제 |
| `del_main` | kill.sh 실행 → 종료 확인 → /data/stableNet/mainnet 폴더 삭제 |
| `del_test` | kill.sh 실행 → 종료 확인 → /data/stableNet/testnet 폴더 삭제 |

스크립트는 Mac 전용이며 sshpass로 SSH 포트 10022에 접속해 `/data/stableNet/script/*.sh`를 sudo로 실행한다. run/restart 계열은 서버 번호 역순으로, 나머지는 정순으로 돈다. gstable 프로세스 존재 여부를 `ps aux | grep gstable`로 확인한다.
