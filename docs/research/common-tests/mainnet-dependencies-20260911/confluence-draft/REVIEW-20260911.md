# 초안 사실 검토 기록 (2026-09-11, 현재 체인 소스 기준)

초안 15장의 사실 주장을 세 체인 소스(go-wemix, go-wbft, go-stablenet)와 실행 도구 소스에서 다시 확인했다. 결과는 "확인"(초안 그대로), "수정"(초안을 고침)으로 나눈다. 근거 위치는 검토용이며 Confluence 초안에는 넣지 않는다.

## 검토하지 못한 것

- 노드를 띄워 실행하지 않았다. 위 확인은 소스 읽기다.
- WEMIX3.0 운영망의 거버넌스 값(최소 팁, 블록 간격, 기본 수수료 상한)은 코드 기본값이 아니라 배포된 컨트랙트 상태라 확인하지 않았다.
- 2차 변경 T-1(풀 누적 잔액)에서 go-wemix가 단건 검사만 한다는 판단은 `core/tx_pool.go`의 단건 검사 코드를 본 것이며, 누적 검사가 다른 곳에 있는지까지는 확인하지 않았다.
