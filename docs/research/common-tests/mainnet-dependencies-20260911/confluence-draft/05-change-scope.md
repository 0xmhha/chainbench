# 공통 테스트 분리 변경 범위

공통 테스트 76개를 세 체인에서 같은 뜻으로 돌리기 위해 바꿀 것을 순서대로 적는다. 앞 단계 없이 뒤 단계를 하면 테스트 수는 늘어도 세 체인에서 같은 뜻으로 돌지 않는다. 노드 프로그램 소스를 바꿔 기능을 맞추는 일은 범위에 없다.

| 순서 | 작업 | 바뀌는 곳 | 완료 기준 |
|---|---|---|---|
| 1 | 테스트 ID 고정 | 공통 테스트 목록, 결과 기록 | 76개 CT ID와 기존 ID 대응이 결과 기록에 남는다 |
| 2 | 체인별 환경 세 벌과 공통 테스트 분리 | 자동 테스트의 환경 선언, 적용 체인 목록 | 같은 테스트 파일이 세 환경으로 각각 돈다. WEMIX4.0 프로그램 이름 불일치를 고친다 |
| 3 | 고정 주소 제거 | 자동 테스트 35개, 테스트 계정 선언 | 테스트에 고정 주소가 없다(0 주소와 상수 주소 제외) |
| 4 | 절차 상수를 프로필에서 넣는 문법 또는 생성기 | 테스트 문법 또는 생성기 | 수수료, 시간, 기대값 상수가 프로필에서 온다 |
| 5 | 로컬 서명 전송 통합 | 실행 도구의 전송 경로 | 계약 생성, 데이터, 가스, nonce, 수수료, 접근 목록, 대납 형식이 로컬 서명으로도 같은 결과를 낸다. 자금 지급, 배포, 부하 전송이 이를 같이 쓴다 |
| 6 | 체인별 정답 계산과 팁 출처 치환 | 계산 규칙, 체인 설정 | 헤더 팁을 읽는 자동 테스트 12개가 체인 무관 입력으로 바뀐다. 기본 수수료, 최소 수수료, 장애 허용 수 정답이 프로필에서 온다 |
| 7 | 거부 사유 문구 표와 판정 강화 | 거부 판정, 테스트의 사유 항목 | 이유가 틀린 거부가 통과하지 않는다 |
| 8 | 기능 사전 확인과 건너뜀 이유 기록 | 기능 확인, 체인 설정 | 계정 코드 위임, P256, 합의 API, 계정 상태 기능이 실제 노드 값으로 판정된다 |
| 9 | 외부 주소 프로필 | 외부 주소 연결, 노드 표 | 공개 RPC에서 노드 역할, 웹소켓, 지표가 프로필대로 동작한다 |
| 10 | 세 체인 일괄 실행과 결과 기록 | 결과 기록, 보고서 | 세 체인 결과가 같은 CT ID로 묶이고 프로그램 해시, 체인 ID, 하드포크 상태, 서명 방식이 남는다 |
| 11 | 회귀 실행 묶음과 준비물 공유 | 실행 순서 목록, 파일 사이 값 전달 | 묶음 A~E가 네트워크 하나에서 순서대로 돌고, 배포 주소와 영수증을 뒤 파일이 이름으로 읽는다. 결과는 CT ID마다 남는다 |
