선정 기준과 실행 전제

핵심 33개: P0 11개 전부, P1 17개, P2 4개, P3 1개. 기존 후보 18개와 신규 테스트 15개다. 나머지 후보는 후속 회귀로 남긴다.

구현·이식·환경·fixture 준비 완료 후 약 10~20시간(2~3일)을 계획한다. 미실측 추정이며 하루 완료를 보장하지 않는다. 각 신규 테스트는 여러 경계값·모드·노드 조합을 포함한다.

신규 테스트는 N-번호를 제안 추적 번호로 병기한다. 기존 명세 ID 미확인은 신규라는 뜻이 아니다. 각 행의 상세 절차에 준비 조건·판정·증거·기존 assertion과 보강 검증의 차이를 정리했다. 모두 미실행이다.
