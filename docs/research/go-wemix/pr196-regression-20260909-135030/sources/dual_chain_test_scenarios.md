# WEMIX Dual-Chain Test 시나리오 명세서 (2-Chain Common Test Suite)

본 문서는 Chainbench 및 테스트 수트 시나리오 중에서 WEMIX 체인 생태계 3종(WEMIX3.0, WEMIX4.0, StableNet) 가운데 **정확히 2개 체인에서만 공통으로 테스트·검증이 가능한** 시나리오를 선별·분류하여 작성한 명세서입니다.

3개 체인 모두에서 수행 가능한 표준 시나리오는 별도 문서에서 이미 다루므로 본 문서에서는 **제외**합니다.

---

## 분류 기준 (Scope & Classification)

각 체인 클라이언트의 실제 소스 코드를 기준으로 판정한 기능 지원 매트릭스입니다.

| 기능                                   | WEMIX3.0<br>(go-wemix) | WEMIX4.0<br>(go-wbft) | StableNet<br>(go-stablenet) |
| -------------------------------------- | :--------------------: | :-------------------: | :-------------------------: |
| 합의 엔진                              |     etcd 기반 SPoA     |       **WBFT**        |          **WBFT**           |
| `istanbul_*` RPC                       |           ✗            |           ✓           |              ✓              |
| WBFT Extra / PrevSeal / RandaoReveal   |           ✗            |           ✓           |              ✓              |
| EIP-7702 SetCode Tx (Type 0x4)         |           ✗            |           ✓           |              ✓              |
| secp256r1 (RIP-7212) precompile        |           ✗            |           ✓           |              ✓              |
| `wemix_getBriocheBlockReward`          |           ✓            |           ✓           |              ✗              |
| Brioche / Croissant 하드포크 블록 보상 |           ✓            |           ✓           |              ✗              |

이 매트릭스에서 2체인 교집합은 다음 두 그룹으로 분리됩니다.

- **그룹 B (WEMIX4.0 + StableNet)**: WBFT 합의, `istanbul_*` RPC, EIP-7702, secp256r1 프리컴파일 — WEMIX3.0 미지원
- **그룹 A (WEMIX3.0 + WEMIX4.0)**: Brioche 블록 보상 로직 및 `wemix_getBriocheBlockReward` RPC — StableNet 미지원

### 참고 사항

- **포함 기준**: 한쪽 체인에 전용 스크립트가 없더라도, 해당 체인의 소스 코드에서 동일 기능 지원이 확인되면 "테스트 가능"으로 판단하여 포함합니다. 이 경우 스크립트가 없는 쪽은 `(전용 스크립트 없음 / <저장소> 코드 지원 확인)`으로 표기합니다.
- WEMIX3.0 전용 chainbench 테스트 스크립트는 저장소에 존재하지 않습니다. 따라서 그룹 A 항목의 실제 스크립트는 WEMIX4.0 기준으로 표기하며, WEMIX3.0 지원 여부는 `go-wemix` 소스 코드로 확인한 사실을 근거로 합니다.
- 그룹 A는 "WEMIX3.0·WEMIX4.0 공통 + StableNet 미지원"이라는 교집합 특성상 대상 기능이 Brioche 블록 보상 계열로 좁습니다.
