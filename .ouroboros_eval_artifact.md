## Changes since the previous approved evaluation (commit 91dc9336)
- A document review against the Seed, behaviour spec, OpenAPI and screen design found 48 gaps (docs/dev/web-ui-gaps.json); all are closed, each with a failing test before its fix. Examples: ChainSurface catalogue and plan fingerprint, session login everywhere, settings screens (credentials, users, audit), job detail and node detail pages, OpenAPI route sync test, multi-server placement and per-node control on a second server.
- Defects found by frozen runs and fixed with RED tests first: fork-promoted producers refused node cleanup; the job form draft restored node cleanup into a new job; a wrong validator argument became 409 instead of 422 (a regression from the previous fix); SSH node observation exceeded its 8 s budget; monitoring filters overflowed a 390 px screen.
- Harness defects (not product): a racy corpus case read a receipt on a lagging endpoint; the fixture restart response could be read before it was written.
- Known structural limitation agreed with the user for a later refactor: the dashboard runs orchestration in-process over internal/app instead of invoking the chainbench CLI or MCP server.
